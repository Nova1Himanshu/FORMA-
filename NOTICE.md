# Model attribution

Ferrari 458 Italia artist model by vicent091036, distributed with the official three.js car example:
https://threejs.org/examples/webgl_materials_car.html

Model license: Creative Commons Attribution 4.0 International:
https://creativecommons.org/licenses/by/4.0/

The three.js repository license inventory identifies the Ferrari model as CC BY 4.0:
https://github.com/mrdoob/three.js/issues/23089

Modifications: disconnected surfaces separated into selectable mesh pieces, positions quantized for display, materials restyled, and interactive removal and reassembly added. Original textures are not reproduced. Attribution also appears inside the viewer.

This is an independent project with no Ferrari affiliation. The model is not factory CAD. Engine geometry and exact manufacturer control behavior are not included; audio and driving behavior are illustrative.

No separate reuse license has been chosen for the custom viewer code.
